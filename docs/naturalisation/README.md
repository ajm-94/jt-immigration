Public official guidance was reviewed on **15 October 2026**. Check the current
ISD guidance and the applicant's personalised portal checklist before lodging.
These blank templates contain no client records.

## Using the tracker

1. Open **Dashboard**, select the route and enter the applicant's name.
2. On **Identity**, use the dropdown ticks for documents uploaded and checked,
   and enter each file reference. Only completed records earn points.
3. On **Residence**, label every active year/period and select the evidence.
   The first five or three slots activate by route. Activate extra slots if the
   qualifying periods span additional years. Each active slot needs an accepted
   100-point Type A and 50-point Type B proof. No points are pooled between years.
4. On **Documents**, complete required items. Conditional items need a Yes/No
   decision; No requires a reason. Add any extra portal/ISD requests on
   **Extra requests**.
5. Review the Dashboard confirmations. **Ready for submission** appears only
   when the recorded points, evidence checks, required documents and final
   confirmations are complete.

The tracker is macro-free. Blue cells are editable; formula cells are protected
against accidental editing. Ticks are dropdown values, not form-control checkboxes.
It detects repeated evidence references within identity/residence and repeated
shared-address references within each partner's set. Use consistent references;
it cannot inspect or authenticate files or detect the same evidence renamed.
The files themselves are not embedded in the tracker.

Readiness is an administrative preparation result based on the user's entries,
not an ISD decision or a guarantee of legal eligibility. Exceptional affidavit
cases may require individual ISD guidance and cannot automatically bypass the
ordinary points gates. Live personalised portal requirements must be reviewed
and recorded manually. Financial records and tax clearance are not treated as
universal additional requirements unless the application or ISD requests them.

These files do not alter the client portal or staff pages.
